# Debate Methods — Index

10 named debate methods. Each reorganizes the team's discussion structure (cognitive modes, role assignments, round structure). Pick one at team launch. For lighter overlays that decorate existing perspective agents without restructuring the team, see [`../decision-masks/`](../decision-masks/). For cross-folder stacks, see [`../composition-recipes.md`](../composition-recipes.md).

> **Note on role assignment**: any debate method below can be paired with [`16-meta-debate-routing.md`](../../../skills/universal/foundations-team-theory/assets/templates/team-theory/16-meta-debate-routing.md) — a meta-round that picks which member fills which role based on capability-aware peer review (Dynamic Role Assignment, Jan 2026: +29.7% over random, +74.8% over uniform).

## Methods

| File | Method | Use when |
|------|--------|----------|
| [courtroom.md](courtroom.md) | Courtroom (plaintiff / defense / judge) | Clear for/against question; need audit trail |
| [delphi-method.md](delphi-method.md) | Anonymous iterated rounds with controlled feedback | Avoid groupthink; surface minority positions |
| [devils-advocate.md](devils-advocate.md) | One agent argues against the consensus | Decision feels too easy; need stress-test |
| [dialectical-inquiry.md](dialectical-inquiry.md) | Thesis / antithesis / synthesis | Two competing positions need explicit reconciliation |
| [polarity-management.md](polarity-management.md) | Both poles of a tension are valid; manage, don't solve | Tradeoff is recurring (centralize vs. decentralize, etc.) |
| [pre-mortem.md](pre-mortem.md) | Imagine the project failed; work backward to causes | Pre-launch risk surface; high-stakes irreversible decisions |
| [scenario-2x2.md](scenario-2x2.md) | 2×2 axis grid maps four future scenarios | Strategic uncertainty across two key variables |
| [six-thinking-hats.md](six-thinking-hats.md) | Rotate 3 agents through 6 cognitive modes | Team is stuck in one mode (too cautious, too optimistic) |
| [socratic-questioning.md](socratic-questioning.md) | Iterative probing exposes hidden assumptions | Stated reasoning seems shallow or assumption-heavy |
| [steel-manning.md](steel-manning.md) | Each side argues the strongest version of the opposing view | Two-party disagreement; want quality over winner |

## How to compose

- **Default for binary decisions**: dialectical-inquiry or steel-manning
- **High-stakes irreversible**: pre-mortem + devils-advocate
- **Strategic uncertainty**: scenario-2x2
- **Recurring tension**: polarity-management
- **Audit trail required**: courtroom (and consider [`08-courtroom-proclaim.md`](../../../skills/universal/foundations-team-theory/assets/templates/team-theory/08-courtroom-proclaim.md) for the rigorous variant)
