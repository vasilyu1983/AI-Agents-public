# Research Workflow

Use this file when the user needs a durable research process instead of ad hoc browsing.

## Staged Loop

1. Define the question and decision it supports.
2. Create a source plan with named primary sources.
3. Gather raw evidence.
4. Normalize findings into a source ledger.
5. Synthesize only after the evidence set is visible.
6. Record what remains unknown.

## Scope Control

- Keep the question narrow enough to finish.
- Break broad topics into subquestions instead of one giant prompt.
- Stop gathering when additional sources stop changing the conclusion materially.

## Primary-Source Rule

- Use official docs, papers, specs, release notes, or vendor statements for volatile claims.
- Use secondary sources only to discover leads or add context.
