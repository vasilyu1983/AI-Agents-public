# Visual Regression Testing Template

Visual regression testing (Playwright `toHaveScreenshot`, snapshot baselines, CI update flow, masking dynamic content, hosted services) is owned by **qa-testing-playwright**. Use [qa-testing-playwright/references/visual-regression-testing.md](../../../qa-testing-playwright/references/visual-regression-testing.md).

Strategy rule kept here: apply visual tests only to stable pages and design-system components, and treat a baseline update as a reviewed change, never an automatic CI step.
