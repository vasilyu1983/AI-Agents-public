# iOS Proof Checklist

- [ ] The scheme, project or workspace path, and target were verified rather than guessed.
- [ ] Tool availability was checked before relying on XcodeBuildMCP or Xcode agent workflows.
- [ ] Any volatile claim was backed by a primary source checked recently.
- [ ] The implementation built successfully in the intended configuration.
- [ ] The app launched on the intended simulator or device.
- [ ] A user-facing proof artifact exists for UI changes.
- [ ] The smallest relevant automated test scope was executed or explicitly deferred.
- [ ] Privacy, entitlement, and third-party SDK implications were reviewed.
- [ ] Residual risks were reported explicitly.
