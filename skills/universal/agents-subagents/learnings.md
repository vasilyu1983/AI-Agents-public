# agents-subagents — Learnings

## Patterns That Work

- [2026-08-29] Parallel writers that must cross-link: put the shared rule text and exact target headings verbatim in every brief, then verify with a hash of the shared sentence plus a link-resolution loop; no gate catches prose-vs-prose drift.
- [2026-08-29] Thesis-challenge panels: ground each blank-context panelist on a different existing skill so verdicts double as a coverage audit; the defender, not a critic, found the real gap (risk-transfer model missing from startup-business-models).
- [2026-08-20] Two-wave remediation with family-prefix ownership (each agent owns BOTH runtimes' files for its families) kept 282 member descriptions byte-identical across Claude/Codex with zero merge conflicts across 8 parallel writers.
- [2026-08-14] On macOS, compute managed-path lexical relativity before resolving the scope so the /tmp to /private/tmp alias stays usable without weakening containment.
- [2026-08-14] Keep canonical agent files on symbolic quality tiers and resolve concrete model IDs during deployment so retirement updates stay centralized without weakening per-role quality routing.
## Mistakes to Avoid

- [2026-09-16] audit_team_coverage.py parses team.yaml by hand and reads owned_files: [] as the string '[]'; read-only teams must use the sentinel 'none - read-only analysis team', matching the other analysis recipes.
- [2026-08-27] A cross-runtime generated plan must resolve each logical member_id to the runtime-native registered agent name; Claude hyphenated agentType values cannot be reused as Codex underscore agent_type values.
- [2026-08-26] Saved workflow rosters can drift from team.yaml while ordinary catalog validation stays green; gate every embedded workflow roster and candidate map against the canonical team recipes in executable tests.
- [2026-08-26] Install-time link breakage hides from repo-side validators: deploy-preset.sh copied Claude member files without rewriting `../../../references/` links (Codex path rewrote, Claude path did not). Fixed 2026-08-26; `validate_catalog_integrity.py` now gates any escaping `../` hop that is not the rewritable shape.
- [2026-08-20] Installer scope gaps are silent: a per-scope code path (codex+user only) skipped [[skills.config]] and model tier for project/repo installs. Fixed same day (commit 32336c28) — when adding an install scope, diff its materialized output against the user-scope output.
- [2026-08-10] Keep repository team recipes outside native runtime team-state directories, and require exact-source symlinks or recorded checksums before installer refresh, prune, or removal.
- [2026-07-11] Two platform-wide Claude Code defaults flipped and this skill still described the old behavior: (1) subagent recursive spawn was banned, now allowed up to depth 5 (v2.1.172+) [SUPERSEDED 2026-08-26: the depth-5 window closed at v2.1.216; default is 3 layers since v2.1.219, configurable via `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` — the "three layers" statement lives in `references/runtime-surfaces.md` §"Claude Agent SDK gotchas", not SKILL.md, and is current]; (2) `Agent` tool calls ran synchronously by default, now default to background (v2.1.198+) [SUPERSEDED 2026-09-02: `run_in_background: false` is not a documented way to force foreground. Under agent-view fork mode — the interactive default — Claude-spawned subagents are background-only and the parameter is unavailable; see `references/runtime-surfaces.md` §"Claude Agent SDK gotchas"]. Also removed an unconfirmed "Agent Teams requires Opus 4.6+ as lead" claim — current docs (checked through v2.1.199) state no model gate. When a skill cites a specific runtime version + behavior pair, re-verify both together at audit time — the version floor can still be true while the described behavior at that floor has since changed.

- [2026-09-02] Freshness stamps that nothing compares to reality carry no information. All 21 top-level references shared a `last_verified: 2026-04-23` while `git log -1` put them between 2026-04-29 and 2026-08-29 — the stamp could not separate a file checked last week from one abandoned in April, and `validate_catalog_integrity.py` returned PASS regardless. Fix: the validator now compares each stamp against the file's last commit date (`git log -1 --format=%cs`) and lists `STALE STAMP` (advisory; blocking under `--strict-freshness`). A date field with no gate behind it is decoration.
- [2026-09-02] Repo-only gates cannot see runtime drift. Every catalog validator passed while the *installed* copies in `~/.claude/agents/` were months behind the repo and diverged on `model`, `effort`, `skills:` and `disallowedTools`. Validate the materialized install, not just the source of truth.
- [2026-09-02] A fabricated error string in a test masks a dead fallback: the test asserted on a message the code never emits, so it passed while the fallback path it was meant to cover was unreachable. Assert against strings taken from the code, and prove the fallback is reached before asserting what it says.
- [2026-09-02] `§"Section Name"` prose cross-references are invisible to every link checker in the repo. Four of them named sections that did not exist (two in SKILL.md, one into a sibling skill, one into a renamed local heading) while file-path link checks reported clean. Headings inside ```` ```markdown ```` fences are the mirror-image trap: they look like sections but generate no anchors, so all 12 of `agent-patterns.md`'s TOC links were dead. Resolve `#fragment` links and `§"..."` refs in the same gate.
- [2026-09-02] Two files claiming authority over one rule is worse than either alone: `context-first-protocol.md` (196 lines) declared itself the single source of truth while `shared-context-pattern.md` (45 lines) was the file SKILL.md actually linked, so readers got the short version and never learned the long one had precedence. Merged into the more-linked file (148 inbound files vs 4) with a pointer stub left behind.

## Domain Knowledge

- [2026-09-21] Claude Code warns when installed agent descriptions exceed 15k tokens (~3.9 chars/token plus name/tools overhead). Keep members near 280 chars; validate_catalog_integrity.py gates 420/member and 48k catalog.
- [2026-08-26] SKILL.md rules must be validator-enforced or assets drift: as of 2026-08-26, 134/141 members declare `disallowedTools: [Agent]` (7 sanctioned lead roles exempt) and 42/42 applicable Bash members carry the non-mutating guard — a state reached only after the 2026-08-20 audit found 0/141 compliance.
