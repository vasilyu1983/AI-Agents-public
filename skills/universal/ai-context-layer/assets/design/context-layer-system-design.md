# Context Layer System Design

## Goal

Describe a reusable app context architecture that serves deterministic product logic and LLM-powered surfaces.

## Sections

1. Entities and source-of-truth systems
2. Derived memory model
3. Retrieval and grounding model
4. Relationship or graph model
5. Context assembly by surface
6. Projection and safety rules
7. Feedback and learning loop
8. Evaluation and observability

## Output Checklist

- source-of-truth map
- memory contracts
- retrieval contract
- graph justification
- context bundle examples
- failure modes
- rollout and eval plan
