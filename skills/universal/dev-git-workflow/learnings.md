## Mistakes to Avoid

- [2026-08-20] Put graph and assembled-harness drift in the staged fast gate, and give catalog-scanning subprocess tests bounded timeouts with enough headroom for parallel full-gate load.
- [2026-08-14] A synthetic index can validate ignored bundle artifacts, but git diff --cached --check must run after real staging because newly tracked patch examples can surface whitespace defects only then.
- [2026-07-11] Graphite moved graphite.dev to graphite.com in Nov 2025 — stale graphite.dev links are a silent-rot risk; re-check vendor domains on every audit, not just version numbers.
## Domain Knowledge

- [2026-09-23] gh-stack availability moved from private to public preview within a few months, and Git feature releases land several times a year. Re-check GitHub's stacked-PR status and git-scm.com before recommending gh-stack over Graphite/manual stacking or relying on a version-gated Git feature.
