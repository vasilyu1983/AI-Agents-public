# Routing Outcome Log

Record one line each time a skill loads (or fails to load) for a real task. The `agents-skills-feedback-loop` scripts read this file.

Format: `YYYY-MM-DD CLASS skill / task — what happened`. CLASS is `WIN`, `STALL`, `MISROUTE` or `WRONG-TRIGGER`.

2026-10-05 WIN agents-skills-feedback-loop / example entry — Replace this line with your first real routing outcome.
