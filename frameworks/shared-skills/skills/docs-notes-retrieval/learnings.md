- 2026-07-11: Audit pass. The token-budgeting table in `references/context-packaging-patterns.md` pinned specific model versions ("Claude 4.x", "GPT-5.4") to fixed context-window sizes — a hard-constraint violation (no model-version pins in prompts/examples) and a currency risk, since context windows now shift roughly quarterly (verified via web search: Anthropic removed the long-context surcharge and made 1M tokens the default on its long-context tier as of March 2026; OpenAI's GPT-5.4 documents a 272k standard tier with a paid tier beyond it). Replaced with generic tier language ("standard current-generation tier," "long-context/frontier tier") plus an explicit instruction to check the current model's published window at build time — this is durable advice that won't rot the next time model numbers change. Also found: `data/sources.json` cited precise engagement stats (exact view counts, bookmark/like ratios) for two X/Twitter posts that WebFetch could not access (HTTP 402) to verify; WebSearch confirmed the posts exist and match the described content, but the specific numbers are unverifiable with available tools and were removed rather than left as unsourced precision — this class of fabricated-looking precision (a real citation dressed up with invented-sounding stats) is worth checking for on every pass through this skill's sources file.
