# Learnings

Dated, append-only observations from applying this skill. See `learnings.consolidated.md` for the pruned/approved distillation.

- 2026-07-11: Full audit pass found the skill's volatile facts had drifted in both directions within ~4 months: some claims were stale (Solidity pinned to "0.8.35 latest stable April 2026" when 0.8.36 shipped; MiCA grandfathering described as "expired 31 Dec 2025" when the EU-wide backstop is actually 1 Jul 2026, with only some member states closing earlier), and one internal inconsistency existed for years without being caught (SKILL.md said Solidity "0.8.35+", the Solidity reference file said "0.8.28+" — the two files disagreed with each other, not just with reality). Also found one likely-fabricated unsourced statistic ("84-Point Security Framework: 36 design patterns, 48 best practices") that had no traceable source and was removed. Lesson: when a fact is pinned as an exact number/date in more than one file, grep the whole skill for that literal value before and after any correction — cross-file drift is easy to miss when editing file-by-file, and vague "recent research" statistics without a named source should be treated as suspect by default in a domain this full of marketing noise.
