# Signal-to-Design Cookbook

## Purpose

This playbook bridges the lab and the product team. The biomarker signal dictionary (`references/biomarker-signal-dictionary.md`) translates physiological signals to primitives in a research context. This cookbook translates what product teams actually observe — session replay patterns, qualitative reports, A/B results, study outputs — to design moves they can ship or test. Each recipe names the hypothesised primitive so the design move is mechanism-anchored, not cargo-cult.

## Recipe Table

| Observation | Hypothesised Primitive | Design Move | Fail Signal | Verification |
|-------------|----------------------|-------------|-------------|--------------|
| Users skip the hero image/headline without reading | Bottom-up salience failure (#1) | Increase contrast on hero; use top-down salience cue (personal pronoun "you", problem statement matching user prior); or remove hero if it cannot earn attention | Users still skip even high-contrast version | First-fixation latency to hero element; click-zone heatmap; scroll depth at hero |
| High dwell time on page, low conversion | Narrative transport without CTA prediction-error scaffold (#4, #12) | Re-prime CTA by planting it within the narrative arc (not after it); use a within-story action cue that confirms the narrative rather than interrupting it | Dwell remains high but conversion still low → hypothesis wrong | Scroll-conditional click rate; A/B test CTA position (in-narrative vs post-narrative) |
| Funnel bounce concentrated mid-flow | Cognitive load + arousal mismatch (#2 + BE #14) | Strip extraneous information from mid-flow screens; enforce one decision per screen; reduce form field count; add progress indicator | Bounce moves to next screen — load was downstream, not where it appeared | Per-screen drop-off funnel; session replay of bounce sessions; time-on-screen distribution |
| Strong week-1 engagement, decay to near-zero by week-3 | Consolidation hook absent (#9) + no anticipation loop (#10) | Add evening consolidation-window notification referencing content from that day; design daily anticipation arc (tease tomorrow's content today); add meaningful milestone at day-14 | Decay moves to week-5 rather than stopping — partial fix only | Day-7 and Day-30 cohort retention curves; notification open rate vs timing cohort |
| Testimonials placed but not converting | Mirror system absent (#6) | Replace headshot with face-forward portrait showing a genuine emotional expression matching the resolution state (relief, clarity, confidence); add first-person voice or video if possible; verify testimonials are real | Conversion still low → emotional expression is wrong or person is not representative | A/B test: face-forward portrait with expression vs static headshot; click-through from testimonial module |
| Users report "felt scammed" or "felt pushed" | Reactance triggered + manufactured arousal (#2 + Reactance framework) | Audit for countdown timers, false scarcity, confirm-shaming, pre-ticked defaults; remove all; run DMCC OCA audit (ethics-operational-checklist.md) | Qualitative "felt pushed" reports continue → pressure mechanic is elsewhere in the flow | Qualitative exit survey; NPS; CSAT post-purchase; DMCC audit log |
| AI chatbot trust collapses after first error | Affiliative warmth / oxytocin-adjacent signal absent from recovery mechanic (#3; note: oxytocin as a universal trust lever is not replicated — design for genuine affiliative warmth, not a neuroendocrine trust mechanism) | Implement explicit error-acknowledgement script (named human voice, not system message); build 3–5 min "cooling" mechanic (matches oxytocin plasma half-life ~3–5 min) before re-engagement; restore prediction prior with "here is what changed" message (#12) | NPS recovery < 50% of pre-error baseline within 30 days | NPS at T+24h and T+7d post-error; session re-engagement rate after error event |
| Anxiety-relief product drives session time but low return visits | Predictive-error budget burned without satiation (#12) + #10 ceiling absent | Design a clear closure beat at session end ("your reading is complete"); implement one-card-per-day cap on the core mechanics; add predictive-confirm copy ("come back tomorrow for X") to set next-session prior | Return visit rate improves but session time drops too far — closure beat is ending sessions too abruptly; adjust timing | Day-2 and Day-7 return rate; session-length distribution before/after closure beat |
| Premium aesthetic test scores high in pre-launch research, flops post-launch | Neuroaesthetic reward without functional delivery (#7 + #10 mismatch) | Audit whether product quality matches the aesthetic tier; if not, either reduce aesthetic tier or invest in functional delivery before re-launch; do not use visual polish to compensate for product gaps | Users continue to cancel post-trial → functional gap is the primary cause | Post-trial cancellation reason (survey); aesthetic satisfaction vs functional satisfaction split in CSAT |
| Push notifications open rate good but in-app action rate is near zero | Consolidation timing wrong (#9) OR cue-behaviour gap (BE #15 habit cue) | Test two variants: (a) shift delivery to evening consolidation window (6–9pm local); (b) bind notification copy to a specific user-side cue that already occurs (morning coffee, commute); measure separately | Neither variant improves in-app action → content relevance is the issue, not timing | Notification open → action conversion rate by cohort (time-of-day and copy-variant) |
| Onboarding completion drops sharply at step 3 | BAS users prefer forward momentum; BIS users need safety confirmation (#5) | Create dual-tone variant: BAS variant ("Let's go — step 3 unlocks your dashboard") vs BIS variant ("Step 3 is a quick safety check — takes 90 seconds"); segment by referral source or explicit preference signal | Both variants drop at step 3 → the issue is content complexity, not tone | A/B test: BAS-frame vs BIS-frame completion rate at step 3; segment by NPS or referral source if available |
| Pupil dilation observed in user study but no behaviour change | Arousal/interest does not imply intent (interpretation trap) | Do not infer purchase intent from dilation alone; pupil dilation = arousal + cognitive effort; add behavioural follow-up gate (stated preference, next-action measure, or A/B test) | Follow-up A/B also shows no effect → dilation indexed cognitive load, not desire; revisit design hypothesis | Paired behavioural measure in same study; subsequent A/B test on the dilating stimulus |
| Voice prosody flat in user testing of onboarding script | Disengagement (#2 flat arousal) | Re-test with higher-relevance or more personalised content; vary prosodic register in voice UX (conversational, not scripted); do not infer dislike from flat prosody — may be calm, not bored | Prosody remains flat even with highly relevant content → recording context artefact; test in more naturalistic setting | Re-test with different content frame; also check for environmental recording confounds (quiet room vs noisy) |
| Users engage with daily content but never share it | Social motivation not activated (#3, #6) | Add a shareable artifact that produces mirror-system activation (a result card, a score, an insight expressed as something worth sharing); ensure the share mechanic delivers social warmth to the sender, not just the recipient | Share rate improves but content engagement drops — users are now optimising for shareability rather than value | Share rate vs session engagement rate; qualitative: "what made you want to share this?" |
| Retention is high but satisfaction (CSAT) is low | Compulsion-design risk — engagement loop without liking (#10 wanting-without-liking split) | Audit for open-ended wanting loops without satiation; add explicit stopping signals; measure wanting vs liking separately (anticipation survey vs post-content satisfaction survey); if gap persists, redesign | Satiation signal reduces engagement dramatically → engagement was entirely anticipation-driven, not value-driven | Berridge wanting/liking separation: survey both pre-engagement anticipation ("looking forward to this") and post-engagement satisfaction ("glad I did this") in the same cohort |
| Feature launches with strong lab neuro scores but weak A/B lift | Ecological validity gap (lab → field generalisation) | Accept that neuro effect sizes in lab do not directly predict conversion lift in field; use the A/B result as the commercial signal; revisit which primitive was actually driving lab response vs field behaviour | A/B continues to show near-zero lift across multiple iterations → retest the mechanism hypothesis; consider that the primitive hypothesis was wrong | Post-hoc analysis: which user segments show the behavioural effect? Was the lab sample representative? |
| BIS-dominant users (identified by referral source or survey) churn after free trial | Prevention framing absent in upgrade flow (#5) | Insert a prevention-frame upgrade variant: "keep your streak, don't lose your insights, protect your access"; A/B against promotion-frame control | Churn reduction in BIS segment triggers churn increase in BAS segment → validate regulatory focus segmentation more carefully | Churn rate by segment (BIS vs BAS proxy); upgrade conversion by copy variant within segment |
| International expansion shows strong UK performance but weak EU conversion | Localisation gap or GDPR consent friction reducing funnel | Check whether explicit consent flow required by GDPR is reducing funnel; also check whether primitives (#5 BIS/BAS orientation, #7 neuroaesthetic register) differ by cultural context | Issue persists after consent flow is optimised → cultural framing of primitives differs; market-specific primitive stack needed | Funnel drop-off by country; consent-acceptance rate; qualitative testing with EU target audience |
| Users complete study but find it invasive and give low post-study satisfaction | Consent experience mismatch — study felt surveilling, not participatory | Redesign debrief to explain value of participation; review consent language for clarity; ensure opt-out was genuinely easy; this is a study-design fix, not a product-design fix | Post-study satisfaction remains low even with clearer consent → reconsider whether this population is appropriate for physiological data collection | Post-study satisfaction survey; qualitative debrief comments; consent withdrawal rate |

## The 4 Question-Archetypes

Most product problems in this domain are one of four archetypes. Use the shortlist to prioritise which primitives to investigate first.

| Archetype | Symptom | Primary Primitive Shortlist | Secondary Check |
|-----------|---------|---------------------------|-----------------|
| **Attention failed** | Low engagement at entry; hero skipped; notification ignored | #1 (bottom-up salience), #12 (prior mismatch), #7 (aesthetic insufficient to reward attention) | Check if #4 narrative frame is absent (no top-down relevance hook) |
| **Trust broke** | "Felt scammed"; NPS drop; post-error churn; testimonials not converting | #3 (warmth signals hollow), #6 (mirror system absent), #12 (prediction violated without earn) | Check Reactance framework; DMCC audit for dark patterns |
| **They engaged but didn't act** | High dwell / open rate; low conversion / action | #10 (anticipation loop not directing toward action), #5 (tone mismatch BIS/BAS), #4 (narrative without CTA scaffold) | Check #8 (somatic close absent at decision moment); BE #14 (cognitive load blocking action) |
| **They acted but regret it** | Post-purchase cancellation; low CSAT despite high conversion; "felt manipulated" | #10 (wanting-without-liking; compulsion design), #7 (aesthetic over-promised function), #3 (warmth signals not backed by care reality) | Vulnerable-user gate: DMCC audit mandatory; ethics-operational-checklist.md |

## Surrogate-Signal Substitutions

When no physiological or neuro tooling is available, map primitives to behavioural proxy metrics. These are correlates, not mechanisms — they confirm a hypothesis but do not explain it.

| Primitive | Lab Signal | Behavioural Surrogate | Tool |
|-----------|-----------|----------------------|------|
| #1 Attention & Salience | Eye-tracking first-fixation; fixation dwell | Scroll depth; click-zone heatmap; dwell time per section | Hotjar, FullStory, ContentSquare |
| #2 Arousal Physiology | GSR phasic spike | Session length; rage clicks; exit rate spike at specific elements | FullStory, Mouseflow |
| #3 Social Bonding | Oxytocin assay (invasive); HRV | NPS; referral rate; community join rate; support contact tone | CRM, NPS tool |
| #4 Narrative Transportation | DMN fMRI; LPP EEG | Time-on-content; scroll completion; saves / bookmarks; share rate | Analytics + CMS |
| #5 BIS/BAS Regulatory Focus | Frontal alpha asymmetry; self-report BIS/BAS scale | Copy variant A/B test by referral source or explicit survey segment | PostHog feature flags + survey |
| #6 Mirror Systems | Facial EMG; mu suppression | Face-present vs face-absent testimonial A/B; video watch-through rate | A/B test; video analytics |
| #7 Neuroaesthetics | fMRI ventral visual; self-report SAM scale | Preference survey; first-impression rating (5-second test); click-through from visual asset | UsabilityHub; Maze |
| #8 Interoception | Insular cortex fMRI; HRV | Post-session somatic-state self-report; open-ended "how do you feel?" after key flow | In-product survey |
| #9 Memory Consolidation | Sleep EEG; hippocampal fMRI; delayed recall test | Day-7 and Day-30 cohort retention; content recall survey 48h post-exposure | Cohort retention analytics |
| #10 Reward Anticipation | VTA BOLD; GSR before reveal | Daily open rate before reveal; click-through on teaser before full content; anticipation survey ("looking forward to this") | Push analytics; in-product survey |
| #11 Embodied Cognition | Sensorimotor fMRI; reaction time to metaphor | Copy variant A/B: body-metaphor vs abstract copy | A/B test |
| #12 Predictive Processing | N400 EEG; P300 | Task completion rate; error rate at novel UI changes; session-initiation rate after product update | Analytics; error event tracking |
