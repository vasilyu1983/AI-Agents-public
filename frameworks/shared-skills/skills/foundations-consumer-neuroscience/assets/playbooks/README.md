# Playbooks Index

This folder contains operational playbooks for applying the 12 consumer-neuroscience primitives in practice. Each playbook answers one operational question; they presuppose familiarity with the primitives (SKILL.md and `references/primitives-overview.md`) and with the meta-frameworks (`references/frameworks-meta.md`).

## Playbooks

| File | One-Line Description | Question It Answers |
|------|---------------------|---------------------|
| [`study-design.md`](study-design.md) | End-to-end protocol for designing and running a neuro-research study — from hypothesis to product decision. | "We want to measure a neural signal. How do we design a study that will produce an actionable result?" |
| [`signal-to-design-cookbook.md`](signal-to-design-cookbook.md) | Recipe table: observed signal or behaviour → hypothesised primitive → design move → verification. | "We observed X in our data or study. What does it mean and what do we change?" |
