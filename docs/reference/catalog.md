The first run returns TASKS_READY with the tasks; run again with args.tasks to build them. Each task runs the feature-delivery stages for its class, then a fresh acceptance check; a failed task blocks its dependants, and the run stops at the first failure unless continueOnFailure is true. Any stop short of DONE returns an escalation; commit each task yourself with the dev-git-workflow skill. Files under .git, .claude, .codex, .agents, .github and other protected paths, and instruction files such as AGENTS.md and CLAUDE.md, are out of reach: a change to one stops the run, so a human edits them outside any workflow. |

Omit board for deterministic local classification; missing or blank required context stops before normal panel dispatch.
